# Welcome

This vault is a PARA-organized second brain, indexed by [Graphify](https://github.com/safishamsi/graphify)
so an agent can query it as a knowledge graph instead of reading every note.

## Map

- [[01-Projects/_Projects Index|Projects]] — active, time-bound efforts
- [[02-Areas/_Areas Index|Areas]] — ongoing responsibilities
- [[03-Resources/_Resources Index|Resources]] — reference material
- [[04-Archive/_Archive Index|Archive]] — completed / inactive

## Keeping the graph fresh

New or edited notes aren't visible to agents until the graph is rebuilt:

```bash
./scripts/graphify-sync.sh
```

See [[README]] (repo root, outside the vault content tree) for full setup.
