# 🧠 ClaudeBrain

An Obsidian second brain, routed by `CLAUDE.md` and synced between machines with git.

- **New machine?** Follow [`SETUP.md`](SETUP.md).
- **Human entry point:** [`Home.md`](Home.md).
- **Claude entry point:** [`CLAUDE.md`](CLAUDE.md) — the router.
- **How it's designed:** [`90-System/Second Brain Levels.md`](90-System/Second%20Brain%20Levels.md) — Level 1–2 of the 5-level second brain model, on purpose.

## Structure

```
CLAUDE.md      ← router: who I am, how I work, where files live
Home.md        ← dashboard
00-Inbox/      ← capture zone (+ daily notes)
10-Projects/   ← active, has an end date
20-Areas/      ← ongoing responsibilities
30-Resources/  ← reference material
40-Archive/    ← done & dormant (never delete, archive)
50-Wiki/       ← People / Companies / Concepts (evergreen entities)
90-System/     ← Memory.md, Templates/, system docs
```
