# Alpaca Markets

**What they do:** Commission-free brokerage built API-first — the broker behind [[COMMAND — Quant Operations Platform]].

## Key facts

- Offers a paper-trading environment (`paper-api.alpaca.markets`) that mirrors live order semantics, which is what lets COMMAND run a full execution path with no capital at risk.
- Serves market data alongside execution, so one vendor covers both quotes and orders.
