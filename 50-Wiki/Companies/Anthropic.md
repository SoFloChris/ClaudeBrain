# Anthropic

**What they do:** AI safety company; makers of Claude and [[Claude Code]], which runs this vault.

## Key facts

- **No first-party embeddings API.** Their official docs state Anthropic does not offer its own embedding model and point users to [[Voyage AI]] — verified against the live docs page, and the reason [[brain_search]] runs local models instead.
- Claude model families as of mid-2026: Claude 5 (Fable, Opus, Sonnet) and Haiku 4.5.
- Publishes the Model Context Protocol (MCP), including an official `memory` server that stores a knowledge graph of entities, relations, and observations — a potential future upgrade path for [[brain_graph]].
